投稿管理ツール

このツールは、運営者が自分で作った短い動画を、自分の YouTube チャンネルと Instagram アカウントへ予約投稿するための個人用ツールです。運営者本人のアカウントだけで使い、ほかの人には提供していません。

プライバシーポリシー

本ツールは YouTube API サービスを使用しています。本ツールを使うことで、YouTube 利用規約に同意したものとみなされます。Google のデータの扱いは Google プライバシーポリシーに従います。

  • 使う情報: 接続したチャンネルの名前と ID、アップロードした動画の ID・タイトル・説明・公開状態と予約日時、認証用のトークン。
  • 使い道: 動画のアップロード、予約日時の確認と変更、公開状態の確認だけに使います。
  • 保存先: 情報は運営者の PC の中だけに保存し、外部のサーバーへ送ったり、第三者に提供・販売したりしません。
  • 削除: 接続を解除するとトークンは PC から削除されます。Google アカウントの権限ページからも、いつでもアクセスを取り消せます。

利用規約

本ツールは運営者の個人用で、一般には提供していません。
